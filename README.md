# Advanced Calculator

A Java-based console application that performs both basic and scientific mathematical operations. The program provides a menu-driven interface that allows users to perform calculations repeatedly until they choose to exit.

## Features

### Basic Operations

* Addition
* Subtraction
* Multiplication
* Division
* Modulus

### Scientific Operations

* Power Calculation
* Square Root Calculation

### Other Features

* Menu-driven interface
* Continuous calculations using loops
* Division-by-zero handling
* Negative square root validation
* User-friendly console output

## Technologies Used

* Java
* Scanner Class
* Loops
* Switch Case
* Conditional Statements
* Math Class

## How to Run

1. Compile the program:
   javac AdvancedCalculator.java

2. Run the program:
   java AdvancedCalculator
